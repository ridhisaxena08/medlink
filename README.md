## 📌 About the Project

**Swasthya Setu** is an integrated digital healthcare management platform developed to make healthcare services more accessible, convenient, and efficient.

The platform provides a centralized environment where patients can discover doctors, manage appointments, track medications, access healthcare assistance, and stay connected with healthcare services.

Our goal is to simplify the healthcare journey by bringing essential healthcare facilities together through a single digital platform.

---

## 🎯 Problem Statement

Healthcare services are often fragmented across multiple platforms, making it difficult for patients to find suitable doctors, schedule appointments, maintain medical information, manage medications, and communicate with healthcare professionals.

These challenges can lead to delays, inconvenience, and gaps in healthcare management.

**Swasthya Setu aims to bridge these gaps** by providing a unified, user-friendly digital healthcare management solution.

## 🚀 Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- MongoDB
- Git

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### 2. Navigate to the Project Directory

```bash
cd medlink
```

### 3. Frontend Setup

```bash
cd frontend-medlink
npm install
npm run dev
```

### 4. Backend Setup

Open another terminal:

```bash
cd backend-medlink
npm install
```

Configure the required environment variables in the backend `.env` file.

Start the backend using the development script configured in its `package.json`.
